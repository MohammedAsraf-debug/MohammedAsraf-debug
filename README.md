### 1. Ationic — Digital Marketing & Web Development

**My agency and digital business.**

- 🌐 Website: [ationic.agency](https://ationic.agency)

### 2. USSCOS — Sponsorship Platform

A web development project designed to connect athletes and groups seeking sponsorship with sponsors looking for suitable opportunities.

- 🎯 Goal: Simplify athlete discovery and sponsorship applications.
- ⚛️ Technologies: React, TypeScript, Vite, Firebase.
- 🔐 Backend services: Firebase Authentication, Firestore, and Storage.
- 🧪 Engineering practices: Form validation, automated testing, and security rules.
- 🚧 Status: Developed in milestones with ongoing verification.

### 3. Sam & Co — E-commerce Website

An e-commerce project focused on delivering a complete online shopping experience.

- 🛍️ Features: Product listings, categories, variants, cart, wishlist, checkout, and order management.
- 👤 Customer features: Authentication and account management.
- ⚙️ Administration: Product and inventory management.
- 🧰 Technologies: HTML, CSS, JavaScript, PHP, MySQL, Firebase Authentication.
- 🚀 Deployment: [samandco.online](https://samandco.online)

### 4. MARK LIV — Local AI Agent

An experimental local AI assistant designed to interact with tools on a personal computer.

- 🤖 Local model integration through Ollama.
- 🧠 Tool-calling workflow for assistant actions.
- 🌐 Local HTTP server and browser-based chat interface.
- 🛠️ Experimental tools for opening URLs, searching YouTube, launching approved applications, and listing permitted files.
- 🐍 Technologies: Python, Ollama, JavaScript, HTML, CSS.
- 🎯 Goal: Explore practical AI agents that can execute useful tasks locally.

### 5. Silken Grace — Fashion E-commerce Concept

- 👗 Focus: Fashion catalog and shopping experience.
